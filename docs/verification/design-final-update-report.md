## 4. 確定業務仕様の反映

- 未ログイン自己登録を廃止し、ログイン画面の導線・イベント・メンバー画面のモード説明・機能概要を整合。初期講師は空環境のローカル管理コマンド、以降はログイン済み講師のメンバー管理と明記した。固定パスワードは記載していない。
- 新人もスケジュールを新規作成できる。既存の編集・削除は社員区分ではなく本人can_edit=1。Homeの管理メニュー説明もメンバー管理とスケジュールを分けた。
- 講師の課題・コメント参照は権限行の存在、更新は別途can_edit=1。レビュー候補には編集権限のある新人も含む。
- 最後の編集可能講師、最後の新人、担当講師、提出履歴の区分変更制約を反映。提出履歴は未提出以外またはコメントあり。権限・ピン・提出・コメントの自動削除は行わない。
- 研修内容はNULL許可。課題解除の保護・値の復元、分類名のtrim後重複検証、未保存変更警告、入力エラーの赤色とARIAを関連シートに反映した。
- 共通Homeナビを戻る手段として採用。スケジュール詳細から一覧への既存の戻り操作は維持。専用ボタンの新設は記載していない。
- Progress成功メッセージ、検索と選択の分離、コメント本人限定・競合・入力保持を反映した。
- 祝日2000〜2150年と保守事項、BCryptのUTF-8 72バイト制限、ID許可文字、現行表示順を記載。未定義の最小長・複雑性・新ソート機能は追加していない。
