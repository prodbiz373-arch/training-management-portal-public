## 不具合候補 B-E2E-001：既存コメントを編集する画面操作がない

- 対象：進捗・課題管理、課題詳細のコメント一覧。
- 再現：専用新人でログイン→対象課題を開く→コメント追加→登録された自分のコメントの操作を確認。
- 期待：既存コメントを編集し、更新後の内容を画面から確認できる。
- 実際：「削除」と「コメント追加」はあるが、既存コメントの編集ボタン・編集入力欄がない。ブラウザDOM上でも編集操作候補0件。編集E2Eを実行できない。
- 根拠：14-trainee-comment.png、comment-edit-controls.json。現在の`frontend/app/(app)/progress/page.tsx`のコメント行は本文と本人用削除ボタンだけを描画する。
- 原因候補：`frontend/lib/progress-api.ts`にはupdateProgressComment、バックエンド/API仕様にはPUTコメント更新があるが、画面側に更新操作が接続されていない。
- 影響：利用者は画面からコメントを訂正できない。登録・本人削除は動作。他人のコメントを編集可能にすることを提案しているものではない。
- 優先度：P2。コメント編集を含む業務フローの完了を妨げる。
- 修正案：仕様に沿った編集権限を確認したうえで、既存PUT・updateCountを利用する編集UIを追加する。今回はアプリ本体を修正していない。勝手なコメント削除・再登録による代替もしていない。

- 初回は同名「追加」ボタンを取り違えたため、テスト補助側の対象選択を修正した。

- reload直後、DOMの再作成中にcheckboxを参照して一度失敗した。新規ログインと画面ロードの完了を待って再取得し、保存保持を確認した。

これらはテスト補助の問題であり、アプリ本体の不具合件数に加算していない。失敗試行も一時ログへ残した。
