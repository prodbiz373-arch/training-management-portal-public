## 仕様確認と変更

browser-e2e-test.md、docs/api/progress.md、Excel基本詳細設計書のPRM_画面編集1 D14・PRM_イベント内容 E15、および既存PUTを確認した。従来のPUTは課題の更新権限を確認するが、投稿者本人の照合はなかった。Excelにも本人限定の明記がない。この相違を変更前に報告し、今回の明示要件「他人の編集禁止」に従って、UIとServiceの両方で投稿者を照合した。Excelは変更していない。

既存の課題アクセス条件も維持する。新人は本人の課題、講師は編集権限のある課題に限り、さらに投稿者本人だけが編集できる。PUTのリクエスト形式は不変、他人の編集は403 ACCESS_DENIEDとなる。

- 本人かつcanCommentのコメントに「編集」を表示し、本文を入力欄へ展開する。
- 既存updateProgressCommentと編集開始時のupdateCountを使用する。成功レスポンスで本文・更新日時・カウンタを置換する。
- キャンセルは変更を破棄する。空白のみ・200文字超過は拒否する。
- 保存失敗・409競合では入力を保持し、既存エラー形式で表示する。競合後はキャンセルして最新データを再取得する必要があり、自動上書きしない。
- 保存中の同期ガードで二重送信を抑止する。編集中は他の更新操作を抑止し、コメント登録・削除と競合させない。
- 既存の画面構成・色・部品のスタイルに合わせた。DB構造・Flyway・設定は変更していない。
