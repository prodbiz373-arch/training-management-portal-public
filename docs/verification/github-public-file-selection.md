# GitHub公開対象の最終選別・画像/検証資料監査（2026-10-18）

## 1. 結論と今回の範囲

GitHubはPrivateを維持する方針。今回GitHubの設定を操作・取得していない。調査と本報告書追加のみで、既存ファイルの加工・削除・ステージング・履歴変更は行わない。

前回C分類48件の選別結果は、**公開する17件、非公開にする16件、修正後に公開する15件**。公開判断は現在のファイル内容に対する候補であり、Public化完了を意味しない。非公開候補も削除していない。

重要な追加所見：基本詳細設計書の52枚の画像のうち、更新済み11枚以外の41枚は旧画面のキャプチャであり、ヘッダーや一覧に氏名・社員ID候補が見える。装飾だけの画像とは扱えない。実在性・公開許諾・合成データの根拠が未確認なので、基本詳細設計書全体を「修正後に公開する」とする。個人名やIDの実値はここへ転載しない。

## 2. 方法・確認範囲

- 現在の追跡済み/未追跡ファイルと前回C48件を読み取り、文書の個人ホーム・一時パス・DB接続先・バックアップ・旧ツール依存を調査した。
- docs配下のMarkdown49件とREADME/セットアップ導線を調査。履歴調査は前回の結果を引き継ぎ、今回全履歴の秘密情報スキャンを再実行していない。
- 現行画像を73点列挙した。Excel埋め込み52、独立した検証PNG12、frontend/publicの9資産（SVG3含む）。同一内容の重複も場所ごとに数える。
- 全73点を一時抽出コピーから作ったコンタクトシートで目視した。独立した検証PNG12点はさらに原寸相当で全件目視した。Excel画像52点はコンタクトシート目視であり、全てを原寸拡大して全小文字を確認したものではない。旧41点の実在性確認、Excel内の小さな文字の原寸確認は残る。
- PNGのeXIf/iTXt/tEXt/zTXt構造、JPEGのEXIF、ImageIOの属性、SVGのXMLを確認。SVG3点は画像メタデータAPIでは読めないためXMLと目視で別途確認し、未読を安全判定へ転用しない。
- OCR単独で安全と判断していない。前回OCRは参考情報として使用し、今回の目視/メタデータ結果と区別する。元画像・Excelは再保存していない。

## 5. 検証資料のリスクと公開可能な情報

| 情報 | 判断 | 対処 |
| --- | --- | --- |
| 個人ホーム絶対パス | 個人識別・環境依存の情報 | 個人アカウント部分をプレースホルダーへ置換。必要なら相対パス化 |
| 一時ディレクトリ/ログ・補助スクリプト | 全てが秘密ではないが第三者に配布されず、再現性を誤解させる | 公開版は「当時の非配布一時証跡」と明記し、実行手順にはrepo内の継続ツールを使用 |
| localhost/127.0.0.1、開発ポート、一般的なDB/schema/ロール名 | 単体で認証情報ではない | セットアップ例・検証条件として必要なら保持。公開サービスの実接続先と混同しない |
| SQL/Flyway checksum、ファイルSHA-256 | 秘密値ではなく整合性の証跡 | 必要なら保持。バックアップ本体や取得先の個人パスとは分ける |
| 画像内の旧社員名・ID | 実在性/同意が不明 | 公開前に根拠確認または合成データへ置換。実値を監査報告へコピーしない |
| 合成テストの氏名・ID・コメント | 報告と目視が整合する範囲で公開可能 | 合成と明示。実資格情報や実在社員の値を流用していないことを管理者も確認 |
| 実パスワード、Cookie、キー、バックアップ本体、生通信ログ | 非公開 | 公開集合へ含めない。今回の候補で流出は確定していないが未知形式まで不存在保証しない |
| 古い画面/未確定仕様の検証報告 | 内容が古いことと秘密情報は別問題 | 調査当時の履歴資料として扱い、最新手順/APIの代わりにしない |
